# PsiApsi

Podstawowa struktura strony internetowej o spacerach i kursach dla psów.

Katalogi:
- `styles/` - pliki CSS
- `scripts/` - pliki JavaScript
- `images/` - obrazy i grafiki
- `data/` - dane przykładowe i treści

Strony:
- `index.html`
- `walks.html`
- `courses.html`
- `about.html`
- `contact.html`
